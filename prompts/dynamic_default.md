# 標準の動的解析指示

指定された検体だけを隔離Guest内で調査する。Hostで検体を解凍・実行せず、ネットワーク、共有、保護設定は変更しない。サブエージェントを使用しない。

1. OS Agentで現在のプロセス・ウィンドウ・デスクトップ状態を確認し、検体起動前の状態を記録する。
2. 原則として通常権限で一度起動し、job_idを保持して終了状態・子プロセス・画面変化を追う。必要なときだけ画面取得・UI操作を行う。応答待ちを重複起動と取り違えない。
3. 権限不足が実際に確認され、今回のGuest昇格が許可されている場合だけ、その理由を記録して再調査する。未知の引数や実行条件を根拠なく変更しない。
4. ファイル作成・変更・削除、プロセス生成、永続化、通信試行、エラーなどを利用可能な情報から確認する。まだHostへ回収されていない原本ログを読めたと報告しない。
5. 時間上限内に、観測事実・操作履歴・観測できなかった点を分けてまとめる。起動失敗や通信不能も解析結果とし、動作させるために隔離や検体の防御回避条件を改変しない。
6. finish_investigationに結果と未解決点を渡す。静的解析や原本ログとの照合が必要な点を明示する。
